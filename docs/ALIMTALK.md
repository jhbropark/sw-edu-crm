# 카카오 알림톡 템플릿 등록 가이드 (SOLAPI)

알림톡은 사전에 **카카오 채널 + 템플릿 심사 승인**이 있어야 발송됩니다. 거래성 메시지(결제 안내·문의 응답)부터 등록하세요. 승인까지 보통 1~3 영업일.

---

## 1. 준비 순서

1. **카카오 비즈니스 채널** 개설 (business.kakao.com) → 비즈니스 인증
2. **SOLAPI** 가입 → 카카오 채널 연동(발신프로필 `pfId` 발급)
3. SOLAPI 콘솔에서 **발신번호 등록**(통신서비스 이용증명원 등)
4. 템플릿 작성 → 심사 제출 → 승인 후 `templateId` 발급

발급받은 값을 `.env`에 매핑:

```
KAKAO_PFID="KAxxxxxxxx"            # 발신프로필 ID
KAKAO_TPL_LEAD_REPLY="..."          # 리드 자동응답 템플릿 ID
KAKAO_TPL_RECEIPT="..."             # 결제 안내 템플릿 ID
SOLAPI_SENDER="01000000000"         # 대체발송용 발신번호
```

---

## 2. 변수(치환) 규칙

- 템플릿 본문의 변수는 `#{변수명}` 형식
- 코드에서 `variables: { "#{name}": "홍길동" }` 로 매핑 (이미 `solapi.ts`에 구현됨)
- 변수만으로 줄 전체를 채우거나, 광고성 표현/과도한 변수는 반려 사유

---

## 3. 템플릿 본문 예시 (그대로 제출 가능)

### (A) 리드 자동응답 — `KAKAO_TPL_LEAD_REPLY`
```
[OOO 교육] 문의 접수 안내

#{name}님, 문의해 주셔서 감사합니다.
빠른 시일 내 담당자가 연락드리겠습니다.

▷ 문의 내용 확인 후 1영업일 내 회신
```
- 변수: `#{name}`

### (B) 결제 안내 — `KAKAO_TPL_RECEIPT`
```
[OOO 교육] 결제 완료 안내

#{name}님, 결제가 정상 완료되었습니다.
· 결제금액: #{amount}원

수강 관련 안내를 곧 전달드리겠습니다.
```
- 변수: `#{name}`, `#{amount}`

### (C) 수료 후 다음 과정 — 캠페인 스텝용
```
[OOO 교육] 다음 단계 과정 추천

#{name}님, 지난 과정 수료를 축하드립니다!
다음 단계 과정 안내를 보내드립니다.
```
- 변수: `#{name}`

> 캠페인 빌더에서 알림톡 채널 선택 시, 스텝의 "템플릿" 칸에 **승인된 templateId**를 입력하세요. 본문이 아니라 ID입니다(현재 `solapi.ts`가 templateId로 처리).

---

## 4. 반려를 피하는 체크리스트

- 광고성 문구 금지(거래성/정보성만). 광고는 별도 "친구톡"·수신동의 필요
- 변수만으로 구성된 문장 금지, 변수 비중 과도 금지
- 링크는 사전 등록된 도메인만, 단축URL 지양
- 채널/발신프로필과 발신번호가 모두 승인 상태인지 확인
- 야간(21시~익일 8시) 광고성 발송 금지

---

## 5. 코드 연결 지점 (이미 구현됨)

- `src/lib/solapi.ts` — `sendAlimtalk`(pfId·templateId·variables·fallbackText)
- 자동응답: `sendLeadAutoReply` (리드 생성 시)
- 결제 안내: `sendReceipt` (결제 승인 시)
- 캠페인 발송: 크론 `send-scheduled`에서 알림톡 채널 처리
- 미승인/실패 시 `fallbackText`로 문자(SMS) 자동 대체발송
